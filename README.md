# Call Caption

Live captions and translation for macOS. Runs on-device using Apple's Speech and Translation frameworks.

## Requirements

- macOS 26+
- Apple Silicon

## Install

Download [`Call-Caption.dmg`](Call-Caption.dmg) and drag **Call Caption.app** to `/Applications`.

## Build & Run

```bash
./build.sh
./run.sh
./package.sh
./test.sh
```
